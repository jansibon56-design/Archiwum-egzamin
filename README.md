# Test egzaminacyjny AU.64 — wersja bez serwera

## Jak uruchomić

1. Rozpakuj paczkę ZIP.
2. Otwórz folder `test_egzaminacyjny_au64_bez_serwera`.
3. Kliknij dwukrotnie plik `index.html`.

Nie trzeba uruchamiać CMD, Pythona ani lokalnego serwera.

## Struktura folderu

```text
test_egzaminacyjny_au64_bez_serwera/
├── index.html
├── style.css
├── app.js
├── questions.js
└── images/
```

## Ważne

Nie usuwaj folderu `images`, ponieważ są w nim ilustracje do pytań.
